## Связь с предыдущими контрольными работами

Проект является SPA-версией интернет-магазина SpookyShop, который ранее разрабатывался с использованием HTML, CSS и JavaScript.

В новом проекте используются React-компоненты, JSX и передача данных через props.

На следующих этапах будут добавлены состояние, поиск, фильтрация, сортировка, формы, маршрутизация и API-слой.

## Запуск проекта

```bash
npm install
npm run dev
```

После запуска открыть локальный адрес, указанный Vite.

Обычно: http://localhost:5173/
